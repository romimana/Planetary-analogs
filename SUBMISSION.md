# NASA Space Apps 2026 submission notes

The [2026 participant terms, updated August 7](https://www.spaceappschallenge.org/legal/) require a challenge-linked solution, source citations including open materials, rights to use submitted materials, and documentation of applicable third-party licenses. The terms allow an OSI-approved license for original work and specify Apache-2.0 distribution for original content when no specific OSI-compliant license is stated. See also the [2026 event page](https://www.spaceappschallenge.org/2026/) for the Team Project Tab and submission deadline.

Suggested license for original code and documentation: Apache-2.0. The repository's source register documents source-specific terms separately.
