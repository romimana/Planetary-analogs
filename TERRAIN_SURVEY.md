# Earth terrain survey

Terrain only is the explorer default. It includes both the original lab-sample locations and this chemistry-independent survey. The [data release](data/earth-terrain-sites.json) contains 526 new 5 km windows in 46 mapped countries or territories, plus one window without a unique country assignment. Of these windows, 462 have a scored GLiM class. The app has 16,952 unique Earth sites across the two pools. Use **Earth sites → Terrain survey windows** to inspect the newly surveyed pool. This is a pilot inventory, with no priority bonus for familiar analog regions.

## GIS sampling and quality controls

1. Use a sparse 3° latitude–longitude grid above 56°S and below 82.75°N, with the [Natural Earth land mask](https://www.naturalearthdata.com/downloads/110m-physical-vectors/110m-land/) as the initial screen. Add small, regular 5×5 grids near 18 named regions, including [NASA reference areas](https://science.nasa.gov/solar-system/analog-explorer/) and [Kīlauea](https://www.nasa.gov/missions/analog-field-testing/what-is-basalt/). Grid centers are proposed comparison windows. A name or regional NASA reference does not identify the actual site of a NASA experiment. The grid is neither equal area nor a census of exposed terrain.
2. Keep a proposed center only when its full 5 km window fits inside a source tile of each product. Sample a 25×25 grid from [ESA WorldCover 2021 v200](https://esa-worldcover.org/en/data-access) by nearest neighbour and require ≥60% in either bare/sparse vegetation (class 60) or snow/ice (class 70), with no missing classifications in that sample. These are estimated cover fractions. A predominantly snowy window can be useful in a polar scenario and requires field inspection before rover use. [WorldCover's manual](https://worldcover2021.esa.int/data/docs/WorldCover_PUM_V2.0.pdf) specifies no Antarctic coverage.
3. Read the native [Copernicus DEM GLO-30 Public](https://registry.opendata.aws/copernicus-dem/) cell centers inside the window and average their elevations into 10×10 nominal 500 m bins using the same local angular footprint as the NASADEM pipeline. Require ≥95% valid heights per bin. Central gradients give median slope, p90 slope and the fraction above 10°. Relief is p90 minus p10 elevation. Local roughness is RMS residual from the four-neighbour mean. The largest gentle patch is the largest four-connected component at slope ≤10°, divided by the number of interior slope cells. These summarize terrain at the window scale. GLO-30 is a digital surface model with different sensor characteristics from NASADEM. Equal output units and bins do not establish identical measurement error. The public tile set also has gaps, and this release excludes tile-crossing windows.
4. Join the center to the same [GLiM regional lithology](https://www.geo.uni-hamburg.de/geologie/forschung/aquatische-geochemie/glim.html) used in the existing rubric and to [Natural Earth Admin 0](https://www.naturalearthdata.com/downloads/50m-cultural-vectors/50m-admin-0-countries-2/) for display filters. The latter uses Natural Earth's published de facto boundaries. Keep missing map evidence null. GLiM represents regional surface lithology at 0.5°, while the terrain surface is summarized over 5 km. Keep the [original planetary map-unit restrictions](GEOLOGY_MATCHING.md), so a target with an uncalibrated geology class uses the remaining active groups. Compute the same 24 Earth reference solar scenarios using the parent JPL SPICE pipeline.

Rebuild using `python build_terrain_sites.py` with the same GIS and SPICE libraries as the Earth expansion, then run `python build_app.py`. Each record retains the source tile URLs, elevation pixel window and SHA-256 of elevation values plus the validity mask, SHA-256 of sampled cover classes, and the GLiM lookup and checksum where available. The release also records the region archive and solar kernel hashes. Out of 2,157 proposed locations, 2,103 fit both tile boundaries and 526 passed cover and terrain validation. Replayed six source windows across six named areas, including exact hash and feature comparisons.

## Ranking and scope

Each ranked list compares candidates using the same active feature groups. With chemistry off, neither eligibility nor the score depends on chemical observations. With chemistry on, candidates need all selected measured components. The measured values are preserved in the original snapshots. A row without measurements receives no estimate and appears in terrain mode. Chemistry and terrain fit their interquartile ranges independently, so toggling chemistry leaves the terrain contribution inputs fixed for common candidates. A region or site-pool filter only narrows the displayed ranking. The geology rubric measures map-unit similarity and uses explicit penalties without an empirical calibration.

JAXA's [AW3D30](https://www.eorc.jaxa.jp/ALOS/en/dataset/aw3d30/) is a candidate for cross-validation rather than an interchangeable raster. [Sentinel-1 and RADARSAT](https://donnees-data.asc-csa.gc.ca/en/dataset/radarsat1) backscatter requires matching incidence, wavelength, calibration and surface conditions before comparing physical roughness with Mini-RF. [Sentinel-2](https://dataspace.copernicus.eu/explore-data/data-collections/sentinel-data/sentinel-2) can add more recent optical context. None of these became numerical matching features in this release. Antarctica requires a separate ice/exposure source, for example a GIS join to [SCAR GeoMAP](https://www.nature.com/articles/s41597-023-02152-9) combined with [REMA](https://www.pgc.umn.edu/guides/stereo-derived-elevation-models/pgc-dem-products-arcticdem-rema-and-earthdem/). Shadow duration requires terrain horizon geometry and a time series.

Contains modified Copernicus DEM data (2021) and ESA WorldCover 2021 data, processed by the ESA WorldCover consortium. The sources, attribution and terms are available on the [Copernicus AWS registry](https://registry.opendata.aws/copernicus-dem/) and the [ESA data access page](https://esa-worldcover.org/en/data-access).
